# install-claude-code-on-windows

Windows に [Claude Code](https://claude.com/claude-code) をインストールし、PATH の設定まで自動で行うバッチファイルです。

## 使い方

1. [`install-claude-code.bat`](install-claude-code.bat) をダウンロードします。
2. ダウンロードしたファイルをダブルクリックして実行します。
3. 「完了しました。」と表示されたら、何かキーを押して画面を閉じます。
4. PowerShell またはコマンドプロンプトを **一度閉じてから開き直し**、次のコマンドで起動します。

   ```
   claude
   ```

> [!NOTE]
> 管理者権限は不要です。インストール先と PATH の設定は、実行したユーザーだけに適用されます。

## このバッチファイルが行うこと

| ステップ | 内容 |
| --- | --- |
| 1. インストール | 公式インストーラー（`https://claude.ai/install.ps1`）を PowerShell で実行します。 |
| 2. 確認 | `%USERPROFILE%\.local\bin\claude.exe` があるか確認します。見つからない場合は `latest` を指定して再試行します。 |
| 3. PATH 設定 | ユーザー環境変数 `Path` に `%USERPROFILE%\.local\bin` を追加します。すでに登録済みの場合は追加しません。 |
| 4. 動作確認 | `claude --version` を実行し、インストールされたバージョンを表示します。 |

## 動作環境

- Windows 10 / 11
- PowerShell（Windows に標準で入っているもの）
- インターネット接続

## トラブルシューティング

**`claude` と入力しても「認識されません」と表示される**
PATH の変更は、新しく開いたターミナルにだけ反映されます。ターミナルをすべて閉じてから開き直してください。それでも起動しない場合は、Windows に一度サインインし直してください。

**「claude.exe をインストールできませんでした」と表示される**
その上に表示されているエラーメッセージを確認してください。ネットワーク接続や、セキュリティソフトによるブロックが原因の場合があります。

**「Windows によって PC が保護されました」と表示される**
インターネットからダウンロードしたファイルを実行するときに表示されることがあります。内容を確認したうえで、「詳細情報」→「実行」を選んでください。

**日本語が文字化けする**
表示が崩れるだけで、インストール処理には影響しません。

## アンインストール

1. `%USERPROFILE%\.local\bin\claude.exe` を削除します。
2. 「環境変数を編集」（スタートメニューで検索）を開き、ユーザー環境変数 `Path` から `%USERPROFILE%\.local\bin` を削除します。
